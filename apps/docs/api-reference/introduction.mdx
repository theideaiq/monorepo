---
title: "API reference"
description: "The endpoints of api.theideaiq.com that partners call."
---

Base URL: `https://api.theideaiq.com`.

- **OpenID Connect** (`/oidc/…`): discovery, keys, the token endpoint and
  userinfo. See [Sign in with The IDEA Pass](/sign-in/overview).
- **The Pass card** (`/oidc/card`, `/oidc/card/check`): the person's card
  with an access token, and door checks with your app's credentials.

Errors are JSON: OAuth errors (`{ "error": "invalid_grant" }`) on the
token endpoint, `invalid_token` (401, with `WWW-Authenticate`) when an
access token is missing or expired. New endpoints will be added under
`/v1/…`.
